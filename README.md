# sdlc-online-shopping-website
A Software Engineering assignment analyzing and selecting the most suitable SDLC model (Agile) for an Online Shopping Website with justification and comparison.

1. Introduction
An Online Shopping Website is a web-based platform that allows users to browse products, add items to a cart, make secure payments, and track orders. It includes features such as user authentication, product search, order management, and customer support.
These systems must be scalable, user-friendly, and adaptable to changing business requirements and user preferences.

 2. Selected SDLC Model
    Agile Model

3. Justification
   
The Agile Model is the most suitable SDLC model for an Online Shopping Website for the following reasons:

- Frequent Requirement Changes
E-commerce platforms frequently update features such as discounts, UI design, and payment options. Agile supports changes at any stage of development.

- High User Involvement
Continuous feedback from users helps improve the overall experience. Agile encourages regular interaction with stakeholders.

- Incremental Development
Features like login, cart, and payment can be developed in phases, allowing early delivery of functional modules.

- Faster Time-to-Market
Agile enables quicker releases, helping businesses stay competitive.

- Continuous Testing and Improvement
Testing is done in every iteration, reducing bugs and improving product quality.

4. Comparison with Other Models

(a)Waterfall Model

Follows a rigid, linear structure
Difficult to accommodate changes after development begins
Not suitable for dynamic applications like e-commerce websites

(b)V-Model

Emphasizes testing but lacks flexibility
Not ideal when requirements evolve frequently

6. Conclusion

The Agile Model is the best choice for developing an Online Shopping Website due to its flexibility, iterative approach, and strong focus on user feedback. It allows continuous improvement, faster delivery, and efficient handling of changing requirements, making it ideal for modern web applications.
